📤 Scheduled sprays → a shared Google Sheet 🧭 walkthrough

Optional, but worth the 3 minutes: SprayCast works fine without it — connect it when you want the whole crew (or the boss) seeing a live list of what's planned without anyone opening SprayCast. Scheduled sprays — and later done/cancel updates — are written to a Google Sheet you own. One-time setup:
  1. Make a Google Form in which every question is short-answer — including the date one: Date, Start, End, Spray, Location, Notes, Status (name them however you like). Leave every question NOT-required, set Settings → Responses → Collect email addresses: OFF — and then click Publish (top right; a form that was never published rejects every row).
  2. In the form's Responses tab click the Sheets icon — that spreadsheet is your shared list (share or publish it like any sheet).
  3. In the form: ⋮ menu → Get pre-filled link → type the words date, start, end, spray, location, notes, status into their matching boxes (a real date typed into the date box works too) → press Get link at the BOTTOM, then its Copy link → paste below. Don't copy the address bar — it carries none of the words you typed.

ℹ About SprayCast

🔒 Privacy statement. There is no account and no SprayCast server. Your farms, condition profiles, watches, scheduled sprays and any readings file you import are stored only in this browser, on this device — an imported file is read here and the file itself is not sent anywhere.

What does leave the browser. Weather requests carrying each farm's coordinates, every time the forecast refreshes, go to Open-Meteo; the town search sends the text you type to Open-Meteo's geocoder. The 🧭 wind map asks Esri for the map tiles you are looking at, and only while it is open.

NWS / weather.gov receives your coordinates too — for the 🦅 forecast option where you have turned it on, and for the 📋 scorecard, which runs on its own for any farm without its own station, because that is where it gets something to check the forecast against.

Only for sources you switch on in ⚙ Setup:NEWA's public station service at Cornell, and LI-COR Cloud — a LI-COR token goes to api.licor.cloud and nowhere else, is stored only in this browser, and is stripped out of backup files and never put in a share link. Someone you hand a backup to gets the station link but must paste in their own token.

If you connect the optional 📤 sheet bridge, scheduled sprays — each carrying the spray's details and the name of the farm it was logged for — are written to the Google Form and Sheet you set up. That is the one place your spray plans can go, and only because you connected it.🔗 Setup share-links carry farms and condition profiles and nothing else — never your scheduled sprays, watches, sheet connection or station token. 💾 Backups are files you keep and hand to whoever you choose.

No analytics, no tracking, no crash reporting, no email address. Nothing else goes anywhere.

⚠ A forecast is a forecast. SprayCast is planning help, not a decision-maker. It rates the hours ahead against limits you set — the product label always wins, and conditions in the yard beat any model. Check them before you pull out.

💾 Your data is yours, and it is only here. Clearing this browser's site data, or reinstalling, takes it with it. Export a backup from ⚙ Setup now and then — that file is also how you hand your setup to a coworker.
